# Innovation Solution Provider LLC — Website

Next.js (Pages Router) + Tailwind CSS.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

## Where things are
- `data/site.js` — all text, phone, address, EIN, social links, image paths
- `pages/index.js` — home page sections (Hero, Intro band, Principles, Feature cards, Success, Contact)
- `components/Navbar.js`, `components/Footer.js` — shared header/footer
- Other pages (`about`, `products`, ...) are placeholders for now

## Images
